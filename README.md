Atuo em **suporte de TI na Track&Field**, sou formado em **Gestão da Tecnologia da Informação** e desenvolvo sistemas web e automações.

Minha experiência em suporte me aproxima das necessidades dos usuários e dos processos das empresas. Levo essa visão para o desenvolvimento de sistemas de atendimento, gestão de estoque e ferramentas que simplificam tarefas repetitivas.

**Meu objetivo profissional é atuar como desenvolvedor backend júnior**, com foco em Python, Django e bancos de dados relacionais.

## Projetos em destaque

### 🎧 [Portal de Chamados — Helpdesk](https://github.com/sonmook/portal-chamados)

Sistema de atendimento de TI com abertura e acompanhamento de chamados, controle de SLA e dashboard de indicadores.

- Perfis de cliente, técnico e administrador, com permissões distintas.
- Login com Google, histórico de interações e registro da solução de cada chamado.
- SLA por prioridade, considerando dias úteis, e indicadores de atendimento.

**Tecnologias:** Python · Django · SQLite · Bootstrap · Chart.js · Django Allauth

### 📦 Estoque Azul — Gestão de estoque

Sistema web **em produção** para gestão de produtos, movimentações, inventário físico, compras e fornecedores.

- Importação por Excel, relatórios e catálogo público de produtos.
- Controle de usuários e permissões, histórico de operações e backups.
- Evolução do sistema com testes automatizados e validação das alterações.

**Tecnologias:** TypeScript · Next.js · React · PostgreSQL · Supabase  
**Código:** repositório privado.

### 🏢 [Gestão de Corretores](https://github.com/sonmook/projetoCorretores)

Aplicação para cadastrar, consultar, editar e excluir registros de corretores, com validação de campos e persistência em banco de dados.

**Tecnologias:** PHP · MySQL · JavaScript · HTML · CSS
